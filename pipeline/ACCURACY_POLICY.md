# RealFifty 정보 정확성 운영 기준

1. 실거래의 근거는 국토부 원본이다. 외부 타입별 거래 목록은 타입 연결의 보조 근거이며 원본에 없는 거래를 추가하지 않는다.
2. 공개 거래 이력은 검증 원본에 존재하는 거래만 사용한다. 해제 거래와 현재 서비스 기준상 직거래는 제외한다.
3. 대표 가격의 전일 차이는 신규 거래 수나 시장 상승·하락으로 집계하지 않는다. 원본 목록 추가·제외도 지연 신고·정정 가능성을 명시한다.
4. 최초 관측, 조회 범위·단지 연결 규칙 변경 시 비교를 보류한다. 같은 정수 면적에 속한다는 이유로 서로 다른 타입의 호가를 전일 비교하지 않는다.
5. 텔레그램과 웹은 동일한 타입별 호가 비교 산출물을 사용한다. 매물 없음·자료 누락은 가격 하락으로 처리하지 않는다.
6. AI 생성 전 원본 갱신 시점, 화면 데이터의 원본 일치, 거래별 원본 존재를 확인한다. 원본이 36시간 이상 오래되면 생성하지 않는다.
7. 한국 시간 기준으로 매일 당월과 이전 2개월 및 각 타입의 최근 거래·관측 최고가가 속한 월을 재조회한다. 일요일에는 당월 포함 최근 12개월, 매월 첫 일요일에는 2014년 이후 전체 기간을 갱신한다. 지역·월별 중복 요청은 제거하며 일반 매매와 분양권·입주권 원본 모두 확인한다. 주요 거래 외 과거 해제·정정은 다음 범위 갱신까지 지연될 수 있다. 수집 시점 이후의 원본 변경을 완전히 예방할 수는 없다.
8. 네이버 수집은 로컬에서만 실행한다. GitHub 호스팅 환경의 수집 작업은 비활성화한다.
9. 검증 실패 시 새 AI 생성·자동 배포 진행을 중단하고 원인을 확인한다. 통과한 데이터도 투자 성과나 체결 가능성을 보장하지 않는다.
